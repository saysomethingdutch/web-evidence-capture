这份是上传到 GitHub 的版本，与本机安装的版本有三处不同：

- 没有 `scripts/project_examples/`：那是一个真实项目的全部工作脚本，含项目主体和人员信息，不上传。
- 没有 `scripts/留痕/`：那是真实项目的留痕 PDF，不上传。
- 正文和脚本里出现的真实公司名，都换成了"某公司""某某某光电"这类占位名。

`SKILL.md` 里提到 `scripts/project_examples/` 的地方，在这份里找不到对应目录，属于正常情况。
